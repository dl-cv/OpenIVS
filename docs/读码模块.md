# 二维码与条码识别

节点类型：`features/barcode_reader`。C# 和 C++ 共用 ZXing-C++ 3.1.1；支持 QR、Data Matrix、Code128 等，不需要模型、加密狗、Python 或新的 GPU 依赖。

## 流程与参数

参考 `Test/data/barcode_flow.json`：`input/image → features/barcode_reader → output/return_json`。读码节点输入一个图像通道，输出原图像通道与读码结果通道。保存的流程端口类型为 `image_chan` / `result_chan`。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `formats` | `""` | 空表示全部；限定格式示例 `QRCode,DataMatrix`、`Code128` |
| `try_rotate` | `true` | 尝试旋转方向 |
| `try_invert` | `true` | 尝试反色；并非所有码制都支持 |

输入是 uint8 灰度、RGB 或 RGBA；非连续 ROI 按真实行步长读取，不改输入。不合法图像或参数报错；没有识别到码返回空目标列表。每张图可以返回多个码。

读码默认按自动两阶段执行：先以原分辨率 `try_downscale=false` 读取，有结果立即返回；为空时才启用 `try_downscale=true` 重试。两轮仍为空时，才对当前图转灰度并做直方图均衡，增强图同样先关闭、后开启 downscale。任一阶段有结果即停止。重试沿用同一 `formats`、旋转和反色参数，输出坐标仍对应原图尺寸。

结果中 `category_name` 是 HRI 解码文本，`category_id=0`，`score=1` **只表示读码成功，不是模型置信度**。`extra_info.barcode_format` 保存码制名称，`extra_info.polyline` 保存首尾闭合的四角点列。模块内部 bbox 为 XYWH，公开流程 JSON 为原图 XYXY；裁剪/变换由既有结果输出节点映射。没有真实像素 mask，不把四边形伪装成分割 mask。

目前测试确认：旋转 QR / Data Matrix / Code128 可读，反色 QR / Data Matrix 可读；ZXing-C++ 3.1.1 的反色扫描跳过 1D reader，**反色 Code128 返回空结果**。`try_invert` 不承诺消除此限制。二进制负载采用 HRI 展示，此节点不提供原始字节接口。

## 依赖与部署

还原 `DlcvCsharpApi/packages.config` 的 `ZXingCpp 0.5.3` 到解决方案 `packages` 目录。C# 使用官方 netstandard2.0 包装器；C++ 延迟加载自身模块目录的同一份 win-x64 `ZXing.dll`，不引入 ZXing 的 C++ STL ABI。版本升级时必须同时核对 C ABI 和跨语言回归。

构建目标自动传播 `ZXingCpp.dll`（C#）、`ZXing.dll` 与许可证文件，正式打包白名单也包含这些文件。仅部署 win-x64，不把包中 Linux/macOS/ARM 运行时带入产品。两个 DLL 合计 3,173,376 字节，约 **3.03 MiB**。详见 `third_party/zxing-cpp/README.md`。

## 自动与人工测试

所有命令从仓库根目录执行。日常构建入口：

```powershell
C:\dlcv\python.exe .cursor/skills/vs-build/scripts/build.py Test/DlcvCSharpTest/DlcvCSharpTest.csproj
C:\dlcv\python.exe .cursor/skills/vs-build/scripts/build.py Test/dlcv_infer_cpp_test/dlcv_infer_cpp_test.vcxproj
```

两个控制台程序均支持：

```text
barcode-selftest <manifest.json> <flow.json> <output.json>
```

manifest 是 `[{"name":"sample","path":"图片绝对路径"}]`，flow 使用 `Test/data/barcode_flow.json`。退出码 0 表示执行和内置校验成功，非 0 表示失败；报告含每图的模块局部结果和公开流程结果。**自有样图的业务文本须人工检查或由调用者断言**，不能只看退出码认为内容符合预期。图片与报告放系统 TEMP，不提交客户图或文本。

可在独立 Python 环境安装 `zxing-cpp==3.1.1`、numpy、opencv-python 后执行合成样例的内容/坐标一致性验证：

```powershell
python Test/verify_barcode.py --output-dir "$env:TEMP/barcode-tests" --cs-exe Test/DlcvCSharpTest/bin/x64/Debug/DlcvCSharpTest.exe --cpp-exe Debug/dlcv_infer_cpp_test.exe

测试脚本从 Test/data/barcode/ 读取固定 QR / Data Matrix / Code128 SVG 并栅格化；低对比度 EAN-13 由测试脚本生成，不依赖客户样图。
```

覆盖灰度/RGB/RGBA、非连续 ROI、旋转/反色、中文文本、多码、空白、过滤、非法参数、重复调用和低对比度 EAN-13 回退；同时执行实际流程，不只测试 DLL 导出符号。

这不是完整安装包发布；正式打包仍走 `1_编译打包.bat`，安装须单独授权。
