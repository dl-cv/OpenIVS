# 编译环境与依赖

## 必需依赖

| 依赖 | 获取方式 | 说明 |
| --- | --- | --- |
| Visual Studio 2019 或 2022（“使用 C++ 的桌面开发”工作负载） | 官方安装器 | 平台工具集取本机默认值（v142/v143），Windows SDK 取本机已安装的最新 10.x，工程不需要改版本号 |
| OpenCV 4.x Windows 包（含 `opencv_world*.lib`） | OpenCV 官方 Windows 包 | 自动匹配已安装版本；用 `OPENCV_INCLUDE_DIR`、`OpenCV_DIR`、`OPENCV_LIB_DIR` 指定路径，或把包放到仓库 `third_party\opencv\build`，或安装到 `C:\OpenCV\build` |
| dlcvpro_infer 头文件 | `pip install dlcvpro_infer` 后取包内 `include` 目录 | 用环境变量 `DLCVPRO_INFER_INCLUDE` 指向该目录，或放到仓库 `third_party\dlcvpro_infer\include`；旧环境默认的 `C:\dlcv\Lib\site-packages\dlcvpro_infer\include` 仍可用 |
| NuGet 包还原 | VS 打开解决方案时自动还原 | ZXingCpp 0.5.3、OpenCvSharp4 等还原到仓库根 `packages` 目录，`packages` 不提交 |

缺少 OpenCV、dlcvpro_infer 时，构建在编译前给出带路径和环境变量的明确错误，不会等到链接阶段。

## Visual Studio 2017

VS2017 的 MSBuild 不识别 `WindowsTargetPlatformVersion=10.0` 的“最新 SDK”写法，会报 MSB8036。工程在 VS2017 下自动改用本机已安装的 10.0.17763.0、10.0.17134.0、10.0.16299.0、10.0.15063.0、10.0.14393.0 中最高版本，平台工具集取 VS2017 默认的 v141。

VS2017 使用限制：

- 本机至少需要安装上述一个 Windows 10 SDK。
- OpenCV 官方 Windows 包用 vc16（VS2019）工具集编译，与 v141 链接可能报运行时库不匹配（LNK2038）。VS2017 需要用 v141 自行编译的 OpenCV，或改用 VS2019/2022。
- 项目代码按 VS2022 的 C++17 维护，VS2017 15.9 以下可能缺少部分语言特性。

## 可选依赖

| 依赖 | 受影响工程 | 获取方式 |
| --- | --- | --- |
| Qt 6 MSVC 64 位 | `dlcv_infer_cpp_qt_demo`、`dlcv_infer_cpp_qt_demo2`、`dlcv_infer_cpp_qt_demo3`、`dlcv_infer_c_qt_demo`、`Test\qt_demo` 下两个测试工程 | Qt 在线安装器，或用 `pip install aqtinstall` 后执行 `aqt install-qt windows desktop 6.10.2 win64_msvc2022_64`。设置 `Qt6_DIR` 指向安装目录（`C:\Qt\6.10.2\msvc2022_64` 或其 `lib\cmake` 目录均可）；未设置时自动在 `C:\Qt`、`D:\Qt` 下查找 |
| 海康 MVS SDK | `CameraManager`、`DlcvCamDemo`、`OpenIVS` 等 C# 工程 | 海康官网安装 MVS，路径 `C:\Program Files (x86)\MVS\Development\DotNet\win64` |
| HALCON 20.11 | `HalconDemo`、`HalconToMatDemo` | MVTec 安装，路径 `C:\Program Files\MVTec\HALCON-20.11-Steady` |

未安装 Qt 时，Qt 工程在编译前报“未找到 Qt6”，并提示设置 `Qt6_DIR`。

## 只编译推理库和 C/C++ 测试程序

核心构建不依赖 Qt、MVS、HALCON。在 VS 里只生成以下工程即可：

- `dlcv_infer_cpp`（推理库）
- `dlcv_infer_cpp_dll_demo`、`dlcv_infer_cpp_dll_demo2`、`dlcv_infer_c_demo`
- `Test\dlcv_infer_cpp_test`、`Test\dlcv_infer_c_test`

命令行示例（在仓库根目录执行）：

```cmd
python build_script\build.py dlcv_infer_cpp\dlcv_infer_cpp.vcxproj --configuration Debug --platform x64
```

生成整个 `OpenIVS.sln` 需要 Qt、MVS、HALCON 全部就绪，其他电脑只验证推理库时不要直接生成解决方案。
